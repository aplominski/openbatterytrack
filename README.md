# Open Battery Tracker

Minimal Android battery monitor: level, health, temperature, voltage, current, cycle count, charge-limiter status.

## Build

```sh
./gradlew :androidApp:assembleDebug
```

APK: `androidApp/build/outputs/apk/debug/androidApp-debug.apk`
